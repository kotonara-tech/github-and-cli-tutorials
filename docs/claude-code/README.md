# 発展編: Claude Code と TDD

本編（第 0〜7 章）で学んだ Git と GitHub の開発フローに、AI のコーディングエージェント **Claude Code** を組み合わせます。
Claude Code は、あなたの指示を受けてファイルを読み、コマンドを実行し、コードを変更してくれるツールです。

発展編の最後の追加課題では、Claude Code と一緒に **t-wada 流のテスト駆動開発（TDD）** で、`todo.sh` に新しい `stats` コマンドを作ります。
チェックボックス付きの「テストリスト」を 1 つずつ消化しながら、Red（失敗するテストを書く）→ Green（テストを通す）→ Refactor（設計を整える）を体験します。

> [!NOTE]
> 発展編は、2026 年 10 月時点の Claude Code（バージョン 2.1 系）をもとに書いています。
> Claude Code は頻繁に更新されるため、画面の表示やコマンドが変わることがあります。各章にある [公式ドキュメント（日本語）](https://code.claude.com/docs/ja/overview) へのリンクで、最新の情報を確認してください。

Claude Console（開発者向けの管理画面）で発行する API キーを使って、使った分だけ支払う方法もあります。詳しくは [第 1 章](01-setup.md#a12-必要なプランと費用) を参照してください。

> [!WARNING]
> 有料プランには、一定の時間あたりに使える量の上限（利用上限）があります。大きなモデルを使ったり、長い作業を任せたりするほど多く消費します。
> 発展編の演習は、Pro プランの利用上限の範囲で取り組めるように、小さな作業に分けています。

## この発展編で作るもの: ハーネス

Claude Code の中では、AI のモデル（Claude）が「情報を集める → 行動する → 結果を確かめる」を繰り返して作業を進めます。この繰り返しを **エージェントループ**（agentic loop）と呼びます。
モデルの周りで、使える道具（ファイルの読み書きやコマンドの実行）と、モデルに渡す情報を管理しているのが Claude Code です。このような「モデルを包む仕組み」を **ハーネス**（harness、馬具の意味）と呼びます（[公式ドキュメント: Claude Code の仕組み](https://code.claude.com/docs/ja/how-claude-code-works)）。

Claude Code の働きは、リポジトリに置く設定ファイルで調整できます。発展編では、練習用リポジトリに次の部品を 1 つずつ追加して、あなたのプロジェクト専用のハーネスを作ります。

| 部品 | 役割 | 章 |
| --- | --- | --- |
| `AGENTS.md` / `CLAUDE.md` | プロジェクトの決まり（テストの実行方法、コードの書き方など）を伝える | [第 2 章](02-claude-md.md) |
| モデルと effort | 作業に合わせて、モデルの賢さと考える深さを選ぶ | [第 3 章](03-models-and-effort.md) |
| skill | よく使う手順（TDD の 1 サイクルなど）を、名前を付けて呼び出せるようにする | [第 4 章](04-skills-and-agents.md) |
| subagent | 別の役割（テストのレビュー役など）を、独立した会話で担当させる | [第 4 章](04-skills-and-agents.md) |
| 権限の設定・フック・モード | 何を許可するか、何を必ず実行するか、どこまで任せるかを決める | [第 5 章](05-harness.md) |
| 検証ループ | テストの結果をもとに、Claude が自分で作業を確かめて進められるようにする | [第 5 章](05-harness.md)・[第 6 章](06-tdd.md) |

完成したハーネスの例は [samples/claude-harness](../../samples/claude-harness/) にあります。各章の演習では、まず自分で作ってから、この例と見比べてください。

## 困ったときは

### `claude` コマンドが見つからない

インストールした直後は、ターミナルを一度閉じて開き直してください（VS Code の統合ターミナルなら、ゴミ箱のアイコンで閉じてから **ターミナル** > **新しいターミナル**）。
それでも見つからない場合は、インストールのコマンドをもう一度実行し、最後に表示されるメッセージ（PATH の設定方法など）に従います（[公式ドキュメント: トラブルシューティング](https://code.claude.com/docs/ja/troubleshooting)）。

### ログインできない

Claude Code は無料プランでは使えません。[claude.ai](https://claude.ai/) の設定画面で、契約しているプランを確認してください。
別のアカウントでログインしてしまった場合は、Claude Code の中で `/logout` を実行してから `/login` でログインし直します。

### 利用上限に達した

利用上限に達すると、Claude Code が上限のリセットされる時刻を表示します。それまで待つか、小さいモデル（[第 3 章](03-models-and-effort.md)）に切り替えます。
`/usage` で、今の利用状況を確認できます。

### Claude が意図しない変更をした

1. 作業中なら <kbd>Esc</kbd> で止めます。
2. 直前の状態に戻したいときは、<kbd>Esc</kbd> を 2 回押すか `/rewind` を実行し、戻したい時点を選びます（[公式ドキュメント: チェックポイント](https://code.claude.com/docs/ja/checkpointing)）。
3. `/rewind` は、Claude がファイル編集の機能で行った変更しか戻せません。コマンドで行われた変更も含めて確実に戻すには、Git を使います。VS Code の **ソース管理** ビューで差分を確認し、**変更を破棄** するか、`git restore <ファイル>` を実行します（本編の [第 2 章](../02-git-basics.md)）。

### `.claude/settings.json` の許可の設定が効かない

Claude Code は、そのフォルダーを信頼するまで、リポジトリの `.claude/settings.json` の `allow`（許可）の設定を使いません。
そのフォルダーで `claude` を対話モードで起動し、表示される信頼の確認で「信頼する（Yes）」を選んでください（[第 1 章](01-setup.md#a14-初めて起動する)）。
